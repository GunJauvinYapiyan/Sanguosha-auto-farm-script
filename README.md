# 三国杀屯田脚本

**Auto火力种田王 V4.5 版本更新说明**

本次 V4.5 版本主要针对游戏大后期的“千次种植疲劳 Debuff 机制”、频繁弹窗阻断、主页 UI 变动以及镜头偏移恢复进行了全方位的底层重构与抗干扰升级。核心在于**彻底剔除主田小麦种植、引入疲劳智能检测与自适应变轨、全流程弹窗 SafeClose 消除链**，让脚本在面对极端疲劳与系统弹窗时依然能够稳定挂机通宵。对库存的要求基本同上一个版本。

注意事项：最近的主页UI貌似有点变化，所以我在控制面板做了如下两点改动：

LOBBY_ENTER_FARM_BTN: [215, 645],

HOME_CHECK_REGIONS: { "右上区域": { rect: [1850, 20, 460, 65], minPixels: 900 }, "左侧区域": { rect: [110, 180, 100, 520], minPixels: 1000 }, "底部区域": { rect: [1275, 945, 875, 90], minPixels: 3000 } }

在使用脚本前，务必确认断线重连机制（包含对主页的检测以及屯田图标的坐标）是否可以正常运行。以及屏幕是否出现自适应异常，导致图标被向两边挤开，这会导致常驻的右下角safeclose点到建造按钮，以及主页检测失败等等。在开启脚本前，要确保主页显示正常，以及偏移检测正常。

### 一、 核心轮种逻辑重构：主田去小麦化与 6+1 纯玉米大后期循环

由于游戏内种植数逼近 800 次时会触发严苛的减产/成熟时间翻倍惩罚，而良田单独收种并不计入常规疲劳。因此 V4.5 大幅精简并优化了轮种结构：

1. **主田彻底剔除小麦**：主田 120 块土地不再参与小麦轮种，小麦全部交由**良田 2 分钟无缝循环稳定产出**，并继续依靠鸡场卖鸡蛋顺带变卖 2 次（`FERTILE_EXTRA_WHEAT_SELLS=2`）进行稳态消化与防爆仓。白天需要种小麦的时候再种，不要直接开刷，避免过快造成1100%debuff。当刷到这个大debuff后，就已经没有拿他刷经验的价值了，不如刷玉米南瓜。
2. **常规循环缩减为 6 轮（水稻→大豆→甘蔗，约 45min/轮）**：
* **第 1～5 次循环**：1水稻（卖1次） → 1大豆（卖2次） → 1甘蔗（卖3次），正常变卖积累资金与经验。
* **第 6 次循环**：水稻收割后留存不卖（第 1 次水稻存量），大豆收割后留存不卖（大豆存量），甘蔗收割后在第 7 轮首步照常卖 3 次（反正之后还要刷的，没必要做存量，脚本替你多刷6次。你可以每天零点后刷一两次，白天再刷几次，直到出大debuff为止）。


3. **第 7 轮二次存量与无限玉米循环**：
* 第 7 轮先种 1 轮水稻（留存不卖，作为第 2 次水稻存量）。
* 水稻收割后，直接切入**纯玉米无限循环（每 1 小时收 1 次，每收 1 次卖 2 次）**。
* 两轮留存的水稻与一轮大豆存量足以平稳支撑鸡场与马场挂机 4 小时以上，结合良田小麦与上方玉米地，实现全自动化挂机过渡。


4. **良田常驻化**：移除了良田的手动开关（满足良田运行的坐标要求应该不苛刻，稍微调一下就能做到），默认常驻开启并自动运行，确保持续为鸡场马场与变卖操作提供原料。如果鸡场开关关闭，小麦的变卖时机会从原来的卖鸡蛋后卖两次，改为每半小时自动变卖两次——可以同时满足马场供应。

### 二、 疲劳 Debuff 智能检测与自适应变轨容灾

为了防止玩家白天手动种植消耗了种植额度导致夜间挂机提前撞上疲劳，V4.5 增加了针对左上角名片下方 `(500, 200)` 与 `(600, 200)` 区域的**红下箭头色相检测（RGB 254, 139, 85）**：

1. **水稻播种触发 Debuff**：若水稻播种后检测到红色下箭头，当前轮水稻收割后留存不卖；紧随其后的大豆收割后留存不卖，甘蔗照常卖；随后立即补种 1 轮存量水稻，等待时间自适应加倍至 **1000 秒**（即使再次弹出 Debuff 也直接忽略），收获后同样不卖；此后直接跳过后续大豆甘蔗，转入纯玉米循环，确保水稻大豆存量达标。
2. **大豆/甘蔗播种触发 Debuff**：当前作物收割后留存不卖，下一轮直接插队补种 1 轮 5 分钟水稻且不卖，收完同样直接转入纯玉米循环。

### 三、 全动作防卡死：弹窗 SafeClose 消除链与良田专属校准

针对游戏中频繁出现的重复书帖、升级等半透明黑底弹窗（会导致外围变暗、误触发偏移判定）：

1. **小麦/水稻 5 秒快速连点**：中心地小麦、水稻转完三圈种植与收割后，强制对右下角空地执行 **5 秒快速点击 SafeClose**，在偏移检测介入前彻底点掉所有连环弹窗。
2. **大豆/甘蔗/主田玉米单点击**：每次种植和收割后均自动停顿 0.5 秒并补点一次右下角 SafeClose，防止单弹窗卡死。
3. **良田专属 SafeClose**：新增良田界面独立 SafeClose 坐标校准与本地持久化保存，具体操作需要你先定位到自己的良田后，寻找一个可以点击的空地。进入良田后，连击收割后先点一次良田 SafeClose 关掉书帖弹窗，再点地呼出菜单；播种小麦脱手后同样先点一次良田 SafeClose，彻底消除良田界面的弹窗风险。
4. **上方玉米地回中防空点补点**：上方玉米地回中坐标若因首次点击消除弹窗而未成功回中，脚本会自动判定并补点第二次回中坐标，且 5 秒常驻检测偏移时会优先补点玉米回中坐标尝试自愈，避免频繁退大厅重连。

V4.0beta+手动种植助手：这次更新了两个东西。第一个是针对前版V4.0的极限优化，采取了小麦→水稻→大豆→甘蔗（≈47min）的循环。前七次循环：1小麦（不卖，靠卖鸡蛋顺带卖2次，良田一直补给） → 1水稻（卖1次） → 1大豆（卖2次） → 1甘蔗（卖3次）。在第8次循环，四种作物均不卖，大豆甘蔗可作为白天存量（鸡饲料也会有一百多的增量）。第9次及之后的循环：第1轮玉米（卖2次） → 第2轮玉米（卖2次） → 1小麦（不卖） → 1水稻（不卖）。前8轮约6.3h，后两轮约2.1h，差不多接近一夜时间。补上白天的日常种植基本足以把前四种作物经验刷干净；上方30土地8次+下方120土地两次，可刷480玉米，玉米经验上限应该也是1000次，只需要下面在刷四轮玉米，然后在上面刷一些补差值就差不多了。其余时间可以单刷南瓜。大后期条件允许的话**建议开启驿站自动装填**。如果有小号的话，建议小号白天多装填糯米糕鸡蛋糕（性价比低，留着多做发糕）、酒类（尤其是甜酒酿，产能很难跟上公告栏任务）、饼类（尤其是南瓜饼，适配它的公告栏好任务太多），风险是运气不好可能会让南瓜或玉米刚好清零（开启自动装填最好多备点玉米南瓜，比如四五十个。晚上任务少做点，农产品尽量都备到10个以上，羊毛也要多留点，增加成功率）。在去掉小麦+水稻+大豆+甘蔗+玉米数值后的仓库最好有700以上的余量，否则多少会有点不安全（比如可能误卖南瓜饼）。该脚本仅适用于超大后期，仓储在接近1400时使用。

优化了偏移检测机制。原来是三图对比动态检测，可以满足平时的局部拖屏需求；缺点是如果偏移点到其他建筑上时重连反应会很慢，容易刷新出错误的参考图被卡在原地。这次采取了更严苛的判定，直接针对游戏开始时的中心地视角去截取右侧鸡舍部分，并同时在5秒间隔的气泡检测内加入偏移检测，一旦检测到偏移立即断线重连回中。如需拖屏或去做别的事，可以直接暂停当前动作。之后返回中心地，点击继续，在右下角弹框选择是否继续当前动作（原来只能选择种植或收割，这在老版单刷小麦的脚本中倒是合适的），选择继续便可以接着前面作物的读秒。哪里（中心地作物、良田、上方玉米）读秒到了就会接着做哪里，没到就会自动点一下右下角并停在原地。优化了鸡场流程，确保准确抓取饲料。若检测到鸡场超过25分钟没气泡，则强制重启鸡场，确保不断供。

驿站装填优化：因为绿植和绿色气泡的检测较难区分，容差调起来不方便，所以我的驿站气泡绿点检测一直采取的是一轮收割后再检测。这在刷钱时期的小麦和水稻上并不会有多少耽搁，但目前已经涉及到甘蔗甚至玉米的种植，这种检测就显得有点偏滞后了。所以我打算利用良田视角做一个新的检测机制（如果不开良田的话就沿用老的），每两分钟去良田种植时也会记录一次截图，良田视角的这块地把它换成泥土地，这样就能实现每两分钟检测一次驿站，一旦有货回中后就能马上发车。

手动种植助手：包含持续单击良田和下方田地各种作物的种植与收割。需要点中心地，并点出种植或收割界面时操作，不含任何计时机制，作为白天手动挡挂机使用。不设甘蔗，因为甘蔗仅靠存量和商店足以应付一天需求，而且晚上刷八次为120×8=960，考虑到一些地漏植，通常在上方30土地多刷两次也足以刷满。如果要在下方土地种甘蔗，直接选中土地后点收割也是一个效果。良田单击主用于冲榜刷经验，经验可达150/h，接近无缝衔接的满鸡场：54×3=162/h。

在代码控制面板调好参数，进入游戏时也有悬浮窗可以中途调节。支持随时暂停和继续动作，继续动作的时刻统一为在中心田地开始种小麦或收割的时候。
在使用鸡场和马场功能时，尽量确保这两个图标在挂机中不发生移位。每次开始游戏前会要求定位这两个图标的位置和卖的位置，在每次收鸡蛋或马奶后到仓库清半，确保仓储足够。
小技巧：鸡场满员加速，16分钟需12饲料，两个铡刀坊15分钟刚好也可供应12鸡饲料；马场满员原速，1小时需12饲料，一个铡刀坊1小时刚好也供应12马饲料。只要在开脚本前确保饲料和小麦水稻都有盈余，图标的位置就可以保证不发生变动。

仓库控制：假设你有100块地，小麦初始值最好在100左右，之后不停计算（+100）/4，会稳定在34，足够同时供应两边工序，之后数量回升。请确保小麦在峰值134时仓库空间充足。使用鸡场功能时，水稻需要有盈余。使用马场功能时，大豆最好保证够一夜使用的库存（脚本不会额外种大豆）。水稻初始设置是4次收鸡蛋后种一轮，收一次卖一次，保证50左右可供4次48个饲料供应。根据鸡和田地数量可在控制面板调整这个周期值。一夜拉满共产生342饲料，仓储充足可考虑使用增量酒，会带来预期84饲料的增益，为白天羊饲料生产提供空间。

田地经济收益：
假设一夜6小时，100块田地。不考虑水稻误差，小麦完成一次种收约75秒，夜跑288次，小麦收益可得57600。使用加速酒加速3秒，约跑次数增加12次，增益2400。同时使用增产酒增值3%，田地收益预估61800。

经验收益：
鸡蛋鸡饲料经验均为3，20×3×3×6=1080;马奶马饲料经验为5+4=9，72x9=648

# 三国杀屯田脚本

一个实现屯田经济自由的AutoJS6自动化脚本，可同时完成田地小麦刷钱和鸡场/马场刷经验，且能应对各种异常场景。

坐标适用分辨率为（2412, 1080），按照图示选中不会拖动屏幕的中间土地开始运行，适合夜间手机挂机刷钱刷经验。

在代码控制面板调好参数，进入游戏时也有悬浮窗可以中途调节。支持随时暂停和继续动作，继续动作的时刻统一为在中心田地开始种小麦或收割的时候。
在使用鸡场和马场功能时，尽量确保这两个图标在挂机中不发生移位。每次开始游戏前会要求定位这两个图标的位置和卖的位置，在每次收鸡蛋或马奶后到仓库清半，确保仓储足够。
小技巧：鸡场满员加速，16分钟需12饲料，两个铡刀坊15分钟刚好也可供应12鸡饲料；马场满员原速，1小时需12饲料，一个铡刀坊1小时刚好也供应12马饲料。只要在开脚本前确保饲料和小麦水稻都有盈余，图标的位置就可以保证不发生变动。

仓库控制：假设你有100块地，小麦初始值最好在100左右，之后不停计算（+100）/4，会稳定在34，足够同时供应两边工序，之后数量回升。请确保小麦在峰值134时仓库空间充足。使用鸡场功能时，水稻需要有盈余。使用马场功能时，大豆最好保证够一夜使用的库存（脚本不会额外种大豆）。水稻初始设置是4次收鸡蛋后种一轮，收一次卖一次，保证50左右可供4次48个饲料供应。根据鸡和田地数量可在控制面板调整这个周期值。一夜拉满共产生342饲料，仓储充足可考虑使用增量酒，会带来预期84饲料的增益，为白天羊饲料生产提供空间。

田地经济收益：
假设一夜6小时，100块田地。不考虑水稻误差，小麦完成一次种收约75秒，夜跑288次，小麦收益可得57600。使用加速酒加速3秒，约跑次数增加12次，增益2400。同时使用增产酒增值3%，田地收益预估61800。
牧场经济收益：
72马奶+270鸡蛋（加速鸡场360/16*2*6=270，喝增产酒能带来约1500现金增益）：72*38+270*28=10296。

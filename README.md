# 三国杀屯田脚本

V4.0beta+手动种植助手：这次更新了两个东西。第一个是针对前版V4.0的极限优化，采取了小麦→水稻→大豆→甘蔗（≈47min）的循环。前七次循环：1小麦（不卖，靠卖鸡蛋顺带卖2次，良田一直补给） → 1水稻（卖1次） → 1大豆（卖2次） → 1甘蔗（卖3次）。在第8次循环，四种作物均不卖，大豆甘蔗可作为白天存量（鸡饲料也会有一百多的增量）。第9次及之后的循环：第1轮玉米（卖2次） → 第2轮玉米（卖2次） → 1小麦（不卖） → 1水稻（不卖）。前8轮约6.3h，后两轮约2.1h，差不多接近一夜时间。补上白天的日常种植基本足以把前四种作物经验刷干净；上方30土地8次+下方120土地两次，可刷480玉米，玉米经验上限应该也是1000次，只需要下面在刷四轮玉米，然后在上面刷一些补差值就差不多了。其余时间可以单刷南瓜。大后期条件允许的话**建议开启驿站自动装填**。如果有小号的话，建议小号白天多装填糯米糕鸡蛋糕（性价比低，留着多做发糕）、酒类（尤其是甜酒酿，产能很难跟上公告栏任务）、饼类（尤其是南瓜饼，适配它的公告栏好任务太多），风险是运气不好可能会让南瓜或玉米刚好清零（开启自动装填最好多备点玉米南瓜，比如四五十个。晚上任务少做点，农产品尽量都备到10个以上，羊毛也要多留点，增加成功率）。在去掉小麦+水稻+大豆+甘蔗+玉米数值后的仓库最好有700以上的余量，否则多少会有点不安全（比如可能误卖南瓜饼）。该脚本仅适用于超大后期，仓储在接近1400时使用。
优化了偏移检测机制。原来是三图对比动态检测，可以满足平时的局部拖屏需求；缺点是如果偏移点到其他建筑上时重连反应会很慢，容易刷新出错误的参考图被卡在原地。这次采取了更严苛的判定，直接针对游戏开始时的中心地视角去截取右侧鸡舍部分，并同时在5秒间隔的气泡检测内加入偏移检测，一旦检测到偏移立即断线重连回中。如需拖屏或去做别的事，可以直接暂停当前动作。之后返回中心地，点击继续，在右下角弹框选择是否继续当前动作（原来只能选择种植或收割，这在老版单刷小麦的脚本中倒是合适的），选择继续便可以接着前面作物的读秒。哪里（中心地作物、良田、上方玉米）读秒到了就会接着做哪里，没到就会自动点一下右下角并停在原地。优化了鸡场流程，确保准确抓取饲料。若检测到鸡场超过25分钟没气泡，则强制重启鸡场，确保不断供。
驿站装填优化：因为绿植和绿色气泡的检测较难区分，容差调起来不方便，所以我的驿站气泡绿点检测一直采取的是一轮收割后再检测。这在刷钱时期的小麦和水稻上并不会有多少耽搁，但目前已经涉及到甘蔗甚至玉米的种植，这种检测就显得有点偏滞后了。所以我打算利用良田视角做一个新的检测机制（如果不开良田的话就沿用老的），每两分钟去良田种植时也会记录一次截图，良田视角的这块地把它换成泥土地，这样就能实现每两分钟检测一次驿站，一旦有货回中后就能马上发车。

手动种植助手：包含持续单击良田和下方田地各种作物的种植与收割。需要点中心地，并点出种植或收割界面时操作，不含任何计时机制，作为白天手动挡挂机使用。不设甘蔗，因为甘蔗仅靠存量和商店足以应付一天需求，而且晚上刷八次为120×8=960，考虑到一些地漏植，通常在上方30土地多刷两次也足以刷满。如果要在下方土地种甘蔗，直接选中土地后点收割也是一个效果。良田单击主用于冲榜刷经验，经验可达150/h，接近无缝衔接的满鸡场：54×3=162/h。

V4.0刷经验良田版更新：利用三国杀良田经验独立结算的机制持续刷小麦，一次可得5小麦+5经验，平均每小时理想收益为150小麦+150经验。一夜6小时算，畜牧业经验收益见文末，约为1458，良田经验收益为其一半。当良田数目达到2或更多时，经验收益有望突破畜牧业，前途无量。良田+玉米版额外增加了单刷玉米的流程，可以保证经验最大化。

V3.5beta版更新：由于马场回中边缘坐标（1500,20）疑似出现无效点击，全靠回中兜底机制没必要，这次改为利用过渡田地二步回中，顺便改动了一些异常检测报错机制。如果你的设备原脚本马场回中没问题的话，无需使用该版。新增专为驿站互助设立的小号刷钱脚本，仅删去了外圈，缩短三秒冷却时间，减少水稻轮距、拖拽次数，并改动了马场铡刀坊的拖拽点位，改为拖糯米糕（刚好冷却时间也是一小时），可直接适用于无铡刀坊三和马场二的情况。前期糕坊格子不足的情况下也可积累大量糯米糕，白天则可用来积累发糕。小号刷钱脚本为过渡使用，等田地数量增多后可切回原刷钱脚本。

V3.5防掉线版更新：针对狗卡在晚上几乎必掉线（多位用户反馈相同情况）所做的预防措施，原理是利用进入屯田模式时布告栏的位置可以提供精确的回城点位，进而确定回中位置。从主页界面进入屯田的位置同样是固定的（目前已放入控制面板），如果之后发生变化，利用脚本的初始红十字定位，然后手动调即可（也可以用AI把这种定位工具单独改出来）。

由于驿站优先级更高，这里针对性地做了右下角驿站的小气泡检测。检测到驿站气泡后，会持续点击快速收获，之后按钮置灰也不影响。默认设置不装载，防止布告栏状态被取消影响回城，且可能想使用填货券的情境（3发糕2米酒酿建议用填货券顶）。断线重连后会先检测左上角水域（请将悬浮窗置于人物名片上，避免遮挡），判定是否去了驿站，如到达驿站，则先清除驿站状态，重新进入游戏回到布告栏位置。

同时处理了三图偏移情况，可以退出游戏后重新进来完成。假如遇到卡死情况，会进行三次拖屏和点击右上角退出按钮尝试，检测是否成功退回主页界面。如果均失败，则进入等待，每分钟截屏一次，直到检测出断线重连的弹窗，点击重新连接按钮回城。

布告栏位置刚好为三气泡共线。
断线重连弹窗能否处理暂时还未测试（我到时候查查日志）。不过驿站优先级更高，理论上也可以针对性地做两手准备，但这个涉及到过于复杂的定位需求，就不做了。最好是控制驿站最后一次的收获时间，即在睡前开启脚本时清空驿站，这样可以保证6小时左右不被优先级占位。同时也处理了三图偏移情况，可以退出游戏后重新进来完成。假如遇到卡死情况，会进行三次拖屏和点击右上角退出按钮尝试，检测是否成功退回主页界面。如果均失败，则进入等待，每分钟截屏一次，直到检测出断线重连的弹窗，点击重新连接按钮回城。

注：有时小麦会提前7秒催熟导致点在元宝加速上，这种情况只要马上暂停，再等7秒手动催熟，然后点击中心土地重新按▶️，收割即可。最多只会发生在脚本刚打开的前一二次，后续稳定跑下来都不会出问题。这个可能是脚本多次重启或pausesleep/sleep功能第一次判定有点冲突，所以每次运行前一两轮最好多守一两轮。

V3.0稳定版更新：修改了检测镰刀的抓取逻辑，确保网络波动状态下不会脱手，稍微牺牲了一点速度。
修复了单次点击催熟完的中心田地后无法弹出镰刀的情况，多次点击直到检测下方画面出现为止。
每次运行时最好重启一下AutoJs6。第一次运行有时会碰到催熟过早，乃至点到元宝加速的情况，这时马上点击暂停，然后重新选中中间田地弹出镰刀，点击继续选择收割即可。后续读秒会恢复正常。

一个实现屯田经济自由的AutoJs6自动化脚本，可同时完成田地小麦刷钱和鸡场/马场刷经验，且能应对各种异常场景。

坐标适用分辨率为（2412, 1080），按照图示选中不会拖动屏幕的中间土地开始运行，适合夜间手机挂机刷钱刷经验。

在代码控制面板调好参数，进入游戏时也有悬浮窗可以中途调节。支持随时暂停和继续动作，继续动作的时刻统一为在中心田地开始种小麦或收割的时候。
在使用鸡场和马场功能时，尽量确保这两个图标在挂机中不发生移位。每次开始游戏前会要求定位这两个图标的位置和卖的位置，在每次收鸡蛋或马奶后到仓库清半，确保仓储足够。
小技巧：鸡场满员加速，16分钟需12饲料，两个铡刀坊15分钟刚好也可供应12鸡饲料；马场满员原速，1小时需12饲料，一个铡刀坊1小时刚好也供应12马饲料。只要在开脚本前确保饲料和小麦水稻都有盈余，图标的位置就可以保证不发生变动。

仓库控制：假设你有100块地，小麦初始值最好在100左右，之后不停计算（+100）/4，会稳定在34，足够同时供应两边工序，之后数量回升。请确保小麦在峰值134时仓库空间充足。使用鸡场功能时，水稻需要有盈余。使用马场功能时，大豆最好保证够一夜使用的库存（脚本不会额外种大豆）。水稻初始设置是4次收鸡蛋后种一轮，收一次卖一次，保证50左右可供4次48个饲料供应。根据鸡和田地数量可在控制面板调整这个周期值。一夜拉满共产生342饲料，仓储充足可考虑使用增量酒，会带来预期84饲料的增益，为白天羊饲料生产提供空间。
